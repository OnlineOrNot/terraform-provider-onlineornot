# OnlineOrNot Provider

Use the provider to manage these resources through the [OnlineOrNot](https://onlineornot.com) API:

- **Uptime Checks** - Monitor website availability and response times
- **Heartbeats** - Monitor cron jobs and scheduled tasks  
- **Status Pages** - Create public status pages for your services
- **Webhooks** - Configure alert notifications
- **Maintenance Windows** - Schedule maintenance periods

## Example Usage

```terraform
terraform {
  required_providers {
    onlineornot = {
      source = "onlineornot/onlineornot"
    }
  }
}

# Configure the provider using the ONLINEORNOT_API_KEY environment variable
provider "onlineornot" {}

# Or configure with explicit API key (not recommended for production)
# provider "onlineornot" {
#   api_key = "your-api-key"
# }
```

## Authentication

The provider requires an API key for authentication.
Create an API key in the [OnlineOrNot dashboard](https://onlineornot.com/app/api-tokens).

Supply the key through the `ONLINEORNOT_API_KEY` environment variable.
The provider also accepts the `api_key` configuration argument.
